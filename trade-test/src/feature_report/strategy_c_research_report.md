## 一、策略概述

### 1.1 策略逻辑

方案C是一个基于布林带压缩和均线穿越的突破策略：

**核心思想**：
- 当布林带收窄时，市场处于压缩状态，即将选择方向突破
- 结合MA192与布林带中轨的位置关系判断趋势方向
- 在压缩状态下等待价格穿越MA192确认突破方向

**入场条件**：
1. **做多条件**：
   - MA192 > BOLL中轨（上升趋势）
   - 收盘价向上穿越MA192
   - 处于有效压缩状态（BOLL带宽百分比 < 阈值，持续足够长时间）

2. **做空条件**：
   - MA192 < BOLL中轨（下降趋势）
   - 收盘价向下穿越MA192
   - 处于有效压缩状态

**出场条件**：
1. **BOLL中轨止损**：价格反向穿越BOLL中轨时止损
2. **硬止损**：固定百分比止损（默认2%）
3. **移动止盈**（可选）：盈利达到阈值后，从最高点回撤一定比例止盈

### 1.2 技术指标

| 指标 | 参数 | 说明 |
|------|------|------|
| MA192 | 周期=192 | 4天均线（30m × 192 = 5760分钟 = 96小时 = 4天） |
| BOLL | 周期=100, 标准差=2.0 | 布林带指标 |
| BOLL带宽 | (上轨-下轨)/中轨 | 衡量波动率 |
| 带宽百分比 | 滚动窗口200 | 相对历史压缩程度 |
| 压缩检测 | 阈值=0.3, 最小持续10bars | 识别压缩状态 |

## 三、策略优势与风险

### 3.1 优势

1. **逻辑清晰**：结合趋势方向（MA192与BOLL中轨关系）和突破信号（价格穿越MA192）
2. **压缩过滤**：只在市场压缩状态下交易，避免在趋势中追高杀跌
3. **风险可控**：BOLL中轨止损提供动态止损位
4. **参数较少**：核心参数只有5个，减少过拟合风险

### 3.2 风险

1. **假突破风险**：压缩后的突破可能是假突破
2. **止损频繁**：BOLL中轨止损可能过于敏感
3. **参数敏感性**：压缩阈值和最小持续时间需要优化
4. **市场状态依赖**：在趋势明显的市场中可能表现不佳

---

## 四、参数优化方向

### 4.1 核心参数

| 参数 | 默认值 | 优化范围 | 说明 |
|------|--------|----------|------|
| compression_threshold | 0.3 | 0.2-0.4 | 压缩阈值，越低越严格 |
| min_compression_bars | 10 | 5-20 | 最小压缩持续时间 |
| hard_stop_pct | 2.0 | 1.5-3.0 | 硬止损百分比 |
| boll_std | 2.0 | 1.5-2.5 | BOLL标准差倍数 |
| boll_stop_enabled | True | True/False | 是否启用BOLL中轨止损 |

### 4.2 优化策略

1. **压缩阈值优化**：
   - 较低阈值（0.2）：更严格的压缩条件，信号更少但质量更高
   - 较高阈值（0.4）：更宽松的压缩条件，信号更多但可能包含假信号

2. **最小压缩持续时间**：
   - 较短时间（5bars）：快速响应压缩，但可能误判
   - 较长时间（15bars）：确认压缩有效，但可能错过早期突破

3. **止损优化**：
   - BOLL中轨止损：动态止损，跟随趋势
   - 硬止损：固定百分比，防止大幅亏损
   - 组合止损：BOLL中轨止损 + 硬止损
