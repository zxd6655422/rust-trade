## ⚠️ 移动止盈的优缺点

### 优点
1. ✅ **显著提高收益**: +55.6%
2. ✅ **降低最大回撤**: -22.9%
3. ✅ **100%止盈成功率**: 所有触发的移动止盈都盈利
4. ✅ **有效锁定利润**: 平均只回吐0.62%

### 缺点
1. ⚠️ **可能过早止盈**: 部分大行情可能被截断
2. ⚠️ **参数敏感**: 不同参数效果差异较大
3. ⚠️ **增加交易频率**: 止盈后可能立即反向开仓

### 推荐配置

```javascript
const trailingConfig = {
    enabled: true,
    activatePercent: 2,    // 盈利达到2%时激活
    drawdownPercent: 0.5,  // 从峰值回撤0.5%时止盈
};
```

### 核心逻辑

1. 当盈利达到**2%**时，激活移动止盈
2. 从最高盈利点回撤**0.5%**时，立即止盈
3. 这样可以有效锁定利润，同时给趋势留出空间
