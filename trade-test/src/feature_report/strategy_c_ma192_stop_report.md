## 一、策略逻辑

### 1.1 入场条件

- MA192 > BOLL中轨（上升趋势）
- 收盘价向上穿越MA192
- 处于有效压缩状态

### 1.2 出场条件

- **MA192止损**：价格跌破入场时的MA192值
- **硬止损**：固定百分比止损（2%）
- **注意**：禁用BOLL中轨止损

## 四、MA192止损 vs BOLL中轨止损对比

| 维度 | MA192止损 | BOLL中轨止损 |
|------|-----------|--------------|
| 止损位 | 入场时的MA192值 | 实时BOLL中轨值 |
| 止损逻辑 | 价格跌破入场时均线 | 价格跌破实时中轨 |
| 灵活性 | 固定止损位 | 动态止损位 |
| 适用场景 | 趋势跟随 | 震荡市场 |

## 五、MA192止损的优缺点

### 5.1 优点

1. **止损位固定**：入场时确定，不会随市场变化
2. **逻辑清晰**：价格跌破均线止损，符合趋势跟随逻辑
3. **减少噪音**：不会因为市场短期波动而频繁止损
4. **持仓更耐心**：给予价格更多波动空间

### 5.2 缺点

1. **止损幅度可能较大**：如果入场时MA192离入场价较远
2. **可能错过反转**：如果市场趋势反转但未跌破MA192
3. **需要更多资金**：较大的止损幅度需要更多资金支持

## 六、下一步优化建议

1. **测试不同MA周期**：尝试MA96、MA144等不同周期
2. **组合止损**：MA192止损 + 硬止损组合
3. **移动止损**：盈利后将止损位移动到入场价
4. **时间止损**：持仓超过一定时间后止损
