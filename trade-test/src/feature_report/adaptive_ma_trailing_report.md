# A9 续：自适应均线止盈研究 v3

> **v2 结论**：趋势健康度验证无增量价值——能达到 20% 利润的交易必然趋势健康。
> **v3 新方向**：
> 1. 趋势衰竭降级：MA480 长拿期间利润从峰值回撤超阈值 → 降回 MA192 锁利
> 2. 早期速度窗口：用入场后前 50 bar 的利润速度作为升级信号
> 3. 切换阈值敏感性：switch_at 从 15% 到 30%
> 口径：对齐生产（slow=480 + vol过滤 + 硬止损→[MA288止损]→止盈规则→趋势反转）。
