### 大浮盈回吐 / 入场即错 的判定口径
- `达到4%激活`：mfe_pct >= 4%（移动止盈激活线）。
- `其中亏损出场`：达到激活线但最终 ret_pct <= 0。
- `其中<=0.5%出场`：达到激活线但最终 ret_pct <= 0.5%（大浮盈几乎吐光）。
- `亏损单中MFE<0.5%`：亏损单里最大浮盈从未超过 0.5%，即“入场就没走出来”。
- `离场后行情`：离场后 20/50/100 根 30m 内，价格朝原持仓方向继续走的幅度。
