# 前端重构开发计划

## 设计理念

按交易者的三种心智模型重新组织页面：**看盘 → 操作 → 分析 → 复盘**

## 目标导航结构

```
📊 概览 (Overview)    — 账户总览、资产、盈亏、持仓摘要、系统健康
📈 行情 (Market)      — K线图、价格行情、策略信号分析、价格预警
💹 交易 (Trade)       — 持仓管理、手动下单、自动交易控制、交易历史
🧪 策略 (Strategy)    — 策略卡片、实时分析、信号历史、绩效对比、参数管理
📋 回测 (Backtest)    — 基础/高级回测、模拟交易（合并原 Backtest + Paper Trading）
⚙️ 设置 (Settings)    — 交易所配置、语言、主题
```

## 技术约定

- **数据获取**: 统一使用 `invoke<Type>('command', { request })` 模式
- **状态管理**: 继续使用 React Context + 组件内 useState，不引入 Redux/Zustand
- **i18n**: 所有用户可见文本必须使用 `t.section.key` 模式
- **组件复用**: 优先复用现有 18 个 trading 组件，只在需要时创建新组件
- **刷新策略**: 卡片类 30s，持仓 15s，曲线 60s
- **样式**: 继续使用 Tailwind + shadcn/ui 组件
