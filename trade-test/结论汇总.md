# MA 趋势回踩策略 · 全量分析结论汇总

> 数据：30m 现货 K 线，未计手续费/滑点。
> 币种：BTC / ETH / SOL（其中 BTC、ETH 含 2017-09 起的扩展历史）+ 新增 BNB / SUI / HYPE。
> 方法：先复刻生产策略做基线回测，再给每笔交易打 27 个监控指标快照做多维度分析，最后用「样本外」检验过滤规则是否真稳健。

---

## 一、一句话结论

1. **策略本体很弱**：约 90% 的交易（MA288止损 + 硬止损）是亏的，只有约 8% 的「移动止盈」交易贡献了全部利润。
2. **亏损有明确规律、且可以被规避**：真正亏钱的是「高波动 + 宽箱体 + 均线过度分离」的入场（集中在 2017、2018、2020、2021 的剧烈行情），用一条「高波动就跳过」的规则能大幅改善收益，并且在**2017-2019 新历史、6 个币种、时间切分、滚动验证**下都成立。
3. **你最初的「交织/箱体震荡会亏」假设，方向反了一半**：均线贴合、窄箱体反而是**赚钱**的；真正要躲的是「高波动 + 宽箱体 + 过度延伸」。

## 三、亏损的结构真相

### 1. 谁在亏钱、谁在赚钱

| 平仓方式 | 占比 | 总收益 | 说明 |
|---|---|---|---|
| MA288止损 | 75% | -2171% | 绝大多数交易，小幅亏损 |
| 硬止损 | 14.5% | -1526% | 深度亏损的主要来源 |
| **移动止盈** | **8.1%** | **+3613%** | **贡献了几乎全部利润** |
| 趋势反转 | 2.4% | +240% | 少量贡献 |

### 2. 盈利 vs 亏损的「持仓画像」（MFE/MAE）

| 分组 | 平均持仓 | 平均最大浮盈 MFE | 平均最大浮亏 MAE |
|---|---|---|---|
| 盈利交易 | 51 根 bar | +5.05% | -0.08% |
| 亏损交易 | 7.1 根 bar | +0.44% | -0.56% |

**通俗理解**：
- 赚钱的单子是「入场后一路浮盈、几乎不浮亏」的趋势单；
- 亏钱的单子是「入场后根本没走起来、很快就被打掉」的噪音单。

## 四、核心发现：到底什么指标决定盈亏

### 1. 单指标相关性（越大越相关，负数=该指标越高越亏）

| 指标 | 相关系数 | 含义 |
|---|---|---|
| atr_pct_14 | -0.065 | 波动率越高越亏 |
| donchian_width_96 | -0.062 | 箱体越宽越亏 |
| bbw_100 | -0.061 | 布林带宽越宽越亏 |
| realized_vol_48 | -0.060 | 已实现波动越高越亏 |
| spread_pct / mean_spread | -0.03~-0.04 | 均线分离越大越亏 |

**规律非常一致：凡是「波动大、箱体宽、均线离得远」的入场，都倾向亏损。**

并且这是**尾部效应**（不是线性）：最极端那 20% 高波动入场的总收益是深度负的（单年可到 -66%），而中低波动区间是正收益。

### 2. 大幅盈利（≥+5%）的共同特征

大盈交易入场时通常：**趋势更老（trend_age 大）、多头动能更强（+DI−−DI 大、RSI 高、价格在区间高位）、趋势分离更明显、量比更高**。

> 一句话：大盈 = 在「已经确立的趋势 + 多头动能 + 适度放量」中入场，随后趋势延续。

## 五、你最初假设的检验结果（重要，方向反了一半）

| 你的假设 | 数据结果 | 结论 |
|---|---|---|
| 均线交织（低分离）→ 亏 | `mean_spread_96 < 0.5%` 反而 **+79%** | ❌ 反了 |
| 长时间窄箱体 → 亏 | `donchian_width_96 < 8%` 反而 **+208%** | ❌ 反了 |
| MA288 交替穿越 MA488 → 亏 | `cross_count_96 ≥ 1` 是 **-31.7%** | ✅ 成立，但**样本外过滤失效** |
| （补充）高波动 + 宽箱体 + 过度分离 → 亏 | 强烈成立 | ✅✅ 这才是真正的亏损 regime |

**真正的亏损 regime 不是「低波窄箱」，而是「高波动 + 宽箱体 + 均线过度分离」——即剧烈波动 / 趋势过度延伸后的追入。**

## 六、可落地的规避规则（重点）

### 规则：入场时「高波动就跳过」

最推荐用 **`realized_vol_48`（48 根 bar 的已实现波动率）**，阈值 ≈ **0.52**（即入场时该值 ≥ 0.52 就跳过）。等价可替换指标：`donchian_width_96 ≥ 8`、`bbw_100 ≥ 6.3`。

|---|---|---|---|

### 样本外验证（证明这不是过拟合）

| 检验方式 | 结果 |
|---|---|
| 时间切分 A（2020-2022 选阈值 → 2023-2026 验证） | 测试段 +194.69% → **+242.05%** ✅ |
| 时间切分 B（2023-2026 选阈值 → 2020-2022 验证） | 测试段 -24.20% → **+112.96%** ✅ |

**结论：高波动过滤是「真结构」，不是只在原样本上灵。**

## 七、BNB / SUI / HYPE 参数矩阵结论

1. **原 BTC/ETH/SOL 模板直接搬过去是亏的**（简单 -8% ~ -33%），参数不能迁移。
2. **新币普遍需要：更紧的硬止损（hs=1.0）+ 更高的移动止盈激活线（act=6.0）**，即「更快止损 + 更耐心持有趋势」。
3. 各自样本内最优：
   - BNB：硬止损 1.0 / 激活 6.0 / 回调 2.0 → 简单 +61.41%
   - SUI：硬止损 1.0 / 激活 6.0 / 回调 2.0 → 简单 +45.29%
   - HYPE：硬止损 1.0 / 激活 6.0 / 回调 0.5 → 简单 +8.96%（**样本仅 304 笔，1.2 年，结论不可靠**）
4. 唯一三个新币复利都为正的稳健组合：硬止损 1.0 / 激活 6.0 / 回调 1.5（但收益平庸，最差仅 +1.44%）。

## 八、必须提醒你的风险点

1. **这些参数/阈值是样本内选的，有过拟合风险**。尤其「贪心组合」把复利推到 +19904% 这种数字不可当真，只能当方向参考。真正可信的是「单条高波动过滤」，因为它通过了时间切分 + 滚动 + 跨币种 + 2017-2019 的四重样本外检验。
2. **HYPE 数据太短（约 1.2 年，304 笔）**，任何 HYPE 结论都要打折。
3. **过滤本质是「整个高波动时期整体跳过」**，不是精准剔除单笔亏损——被移除组胜率仍 ≈14%（与基线持平），它靠的是「高波动期亏损幅度极大」而不是「精准选中亏损单」。这跟你最初「按时间段规避」的思路是一致的。
4. **未计手续费/滑点**。本策略交易频率很高（胜率仅 14%，大量小止损），加上手续费后表现会更差，所以过滤规则能「减少无效交易」这一点反而更有价值。

---

## 九、建议下一步

1. **落地为参数化过滤器**：把「入场时 realized_vol_48 ≥ 阈值 跳过」做成策略的一个开关（类似现有的 slope/bbw/vol 过滤器），阈值建议 0.5 附近，可针对每个币种用滚动窗口再微调。
2. **对 BNB/SUI 做同样的样本外验证**（目前只做了 BTC/ETH/SOL 跨币种，新币参数是样本内选的）。
3. **等 HYPE 数据更长后再回看**。
4. **加入手续费/滑点敏感性测试**，看过滤规则在真实成本下是否依然成立。
