## 一、分析逻辑

### 1.1 BOLL接触定义

- **接触上轨**：价格高点或收盘价在上轨1%范围内
- **接触下轨**：价格低点或收盘价在下轨1%范围内

### 1.2 过滤规则

- **频繁接触下轨不做多**：在滑动窗口内，如果接触下轨次数超过阈值，则不做多
- **频繁接触上轨不做空**：在滑动窗口内，如果接触上轨次数超过阈值，则不做空

### 3.2 过滤效果分析

1. **减少频繁接触时的入场**：过滤掉在压缩期间频繁接触上下轨的信号
2. **提高信号质量**：只在价格突破时入场，避免在震荡中频繁交易
3. **减少假突破**：频繁接触上下轨可能是假突破的信号
